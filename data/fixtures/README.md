# Data — Fixtures

This directory contains small, hand-crafted test fixtures for unit and integration tests.

These are NOT the large synthetic datasets used for evaluation.
Those are generated by `data/generators/` and stored in `data/generated/` (gitignored).

## Conventions

- Fixtures are small (< 100 records typically)
- Each fixture has a clear, documented purpose
- Fixtures are checked into version control
- Use CSV for tabular data, JSON for structured records
