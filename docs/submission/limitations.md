# Limitations & Scope Boundaries — FinResolve AI

## 1. Prototype Status
FinResolve AI is an advanced prototype developed for the Razorpay AI Builder Internship 2026 technical evaluation.

## 2. Explicit Scope Invariants
- **No Real Money Movement**: Real financial execution, gateway mutations, and live bank payouts are strictly out of scope.
- **Simulation Only**: All corrective actions operate exclusively in virtual deep-cloned memory.
- **Synthetic Datasets**: Benchmark evaluation is conducted on deterministically generated synthetic datasets with controlled corruption archetypes. Live bank integrations (e.g. real-time NPCI/UTR webhooks) are simulated.
