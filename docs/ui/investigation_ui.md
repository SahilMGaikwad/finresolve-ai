# AI Investigation Console Specification

## 1. Overview
The **AI Investigation Console** (`apps/web/components/investigator/InvestigationPanel.tsx`) communicates the evidence-grounded findings generated by the AI Financial Investigator.

## 2. Invariants & Display Controls
- **No Chain-of-Thought Leaks**: The interface exposes structured factual claims and agent tool trace steps, never raw prompt tokens or speculative internal reasoning.
- **Evidence-Grounded Factual Claims**:
  - Each claim statement is displayed with its entity reference, claimed field, and claimed value.
  - The `ClaimValidator` verification status is surfaced via unambiguous badges: `[ VERIFIED ]` (green) or `[ CONTRADICTED / UNSUPPORTED ]` (crimson).
- **Ranked Diagnostic Hypotheses**: Root-cause causes ranked with plausibility scores and verified evidence citations.
- **Sequential Agent Trace**: Step-by-step audit record of tool calls (`get_case_overview`, `get_evidence_items`, `simulate_resolution_plan`, `evaluate_plan_policy`).
