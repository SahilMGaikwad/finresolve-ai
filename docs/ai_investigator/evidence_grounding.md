# FinResolve AI — Evidence Grounding & Claim Validation

## 1. Factual Claim Verification Architecture

Every factual statement generated by the AI Investigator is structured as a typed [`FactualClaim`](file:///Users/sahilgaikwad/finresolve-ai/data/schemas/investigation.py):

```python
class FactualClaim(BaseModel):
    claim_id: str
    claim_text: str
    claimed_entity_id: str
    claimed_field: str
    claimed_value: Any
    evidence_ids: list[str]
    verification_status: ClaimVerificationStatus  # VERIFIED | UNSUPPORTED | CONTRADICTED
    verification_reason: str
```

---

## 2. Validation Rules

1. **Entity Existence**: The `claimed_entity_id` must exist within the observed records of the active case.
2. **Evidence Citation**: The claim must cite $\ge 1$ verified `Evidence` item ID produced by deterministic reconciliation rules.
3. **Value Accuracy**: The `claimed_value` must match the observable record's integer minor unit amount or status without deviation.
4. **Unsupported Handling**: Any claim that fails verification increments `unsupported_claims_count` and prevents automated resolution.
